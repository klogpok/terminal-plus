# Процессами владеет Сервер DevPanel, а не UI

Все Сервисы и Сессии принадлежат Серверу DevPanel и живут, пока работает он, а не пока открыта вкладка браузера. UI — один из нескольких равноправных клиентов. После перезагрузки страницы он заново подключается к уже работающим процессам и получает их буферы. Выход из DevPanel означает остановку Сервера (кнопка в UI или закрытие консоли), а не закрытие вкладки. Так случайное закрытие или перезагрузка вкладки не обрывает ни dev-серверы, ни диалог с Claude. Цена решения: в веб-режиме нужна явная кнопка выхода и защита API Ключом доступа.

## Considered Options

- **Процессы привязаны к последнему подключённому клиенту** (останавливать всё через ~10 с после отключения последнего WebSocket). Отклонено: пользователь без опыта легко потеряет работу, закрыв вкладку.
- **Только один клиент одновременно.** Отклонено: повторный запуск `.bat` открывает вторую вкладку, и вытеснение первой стало бы сюрпризом.
