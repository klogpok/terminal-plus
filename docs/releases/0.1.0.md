# DevPanel 0.1.0: the desktop app on Tauri

The desktop app is rebuilt on Tauri. It looks and works as before (window, tray menu, Start with Windows, error boxes), but the installer is about half the size and the app takes about a third of the disk space.

## If you have the old (Electron) DevPanel: uninstall it first

Before installing this version, uninstall the old DevPanel (Settings > Apps > DevPanel > Uninstall). The new installer does not remove it.

If you keep both, the old app's Start with Windows entry keeps launching it at every sign-in. The two apps then compete for the same port, and one of them shows "DevPanel already runs" at every sign-in.

## What is kept

- Your Workspace (Repos, Services), Local Configs and UI Language are kept: they live in the shared data folder `%APPDATA%\DevPanel`, which neither uninstalling the old app nor installing the new one touches.
- The Theme falls back to "System theme" once, after the switch: it is stored per browser, and the new window does not inherit the old one's storage. Pick your Theme again in the settings.
- Start with Windows starts off. Turn it on again in the tray menu if you want it.

## Русский перевод

# DevPanel 0.1.0: десктопное приложение на Tauri

Десктопное приложение пересобрано на Tauri. Выглядит и работает оно как раньше (окно, меню в трее, запуск вместе с Windows, окна ошибок), но установщик примерно вдвое меньше, а на диске приложение занимает примерно втрое меньше места.

## Если у вас старый DevPanel (на Electron): сначала удалите его

Перед установкой этой версии удалите старый DevPanel (Параметры > Приложения > DevPanel > Удалить). Новый установщик его не удаляет.

Если оставить оба, запись автозапуска старого приложения продолжит запускать его при каждом входе в систему. Тогда два приложения будут бороться за один порт, и одно из них при каждом входе будет показывать «DevPanel уже работает».

## Что сохраняется

- Workspace (репо, Сервисы), Локальные конфиги и Язык интерфейса сохраняются: они лежат в общей папке данных `%APPDATA%\DevPanel`, которую не трогают ни удаление старого приложения, ни установка нового.
- Тема один раз сбросится на «как в системе» после перехода: она хранится отдельно в каждом браузере, а новое окно не наследует хранилище старого. Выберите Тему заново в настройках.
- Запуск вместе с Windows изначально выключен. Включите его снова в меню трея, если он нужен.
